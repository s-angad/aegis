For full project details, system architecture, and backend quickstart instructions, please refer to the main repository documentation:

👉 **[AEGIS Project README](../README.md)**

## 🛠️ Local Frontend Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the AEGIS Command Center.
